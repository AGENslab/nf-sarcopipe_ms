# Supplementary Figure 1 – Robustness of de novo candidate detection and evaluation of miRDeep2 novel predictions.

This directory contains the scripts used to generate Supplementary Figure 1 of the manuscript.

---

## Supplementary Figure S1A – CD-HIT clustering summary

### Scripts

- FigureS1A_build_presence_matrix.py
- FigureS1A_compute_core_sets.py
- FigureS1A_generate_summary_table.py

### Output

- Presence/absence matrix after CD-HIT clustering.
- Core candidate summary tables.
- Cluster statistics used for downstream analyses.

**Note**

The Venn diagrams shown in this panel were assembled manually from the summary tables generated by the pipeline.

---

## Supplementary Figure S1B – BrumiR-RF core candidates (presence threshold = 1.0)

This panel was assembled manually from the core candidate summary tables generated in Supplementary Figure S1A.

No additional scripts were required.

---

## Supplementary Figure S1C – Binary presence of miRDeep2 novel candidates

### Script

- FigureS1C_heatmap_miRDeep2_novel_binary.R

### Output

- Binary heatmap showing the presence/absence of predicted novel miRNAs across all samples using the miRDeep2 probability threshold (p = 0.3).

---

## Supplementary Figure S1D – miRDeep2 differential expression

### Script

- FigureS1D_volcano_miRDeep2.R

### Output

- Volcano plot showing differential expression of miRDeep2-known miRNAs.

---

## Supplementary Figure S1E – BrumiR-RF differential expression

### Script

- FigureS1E_volcano_BrumiR.R

### Output

- Volcano plot showing differential expression of BrumiR-RF candidate miRNAs.

---

## Notes

The differential expression volcano plots shown in Supplementary Figures S1D and S1E were generated using the same original plotting script (`plot_volcano_single_method.R`) with different input datasets corresponding to each miRNA discovery approach.

Manual figures (S1A and S1B) were assembled directly from the summary tables produced by the pipeline and therefore do not have dedicated plotting scripts.
