# Figure 5 – Integrated miRNA–mRNA regulatory landscape combining dataset-derived and biologically prioritized predicted targets

This directory contains the scripts used to generate the analyses presented in Figure 5 of the manuscript.

---

## Figure 5A – Coherent miRNA–mRNA regulation

This panel is a conceptual schematic illustrating coherent miRNA–mRNA regulation.

The diagram was prepared manually and summarizes the inverse relationship expected between miRNA and target mRNA expression following seed-based target prediction and coherence filtering.

---

## Figure 5B – Progressive prioritization of miRNA–mRNA interactions

### Scripts

- Figure5B_plot_progressive_target_prioritization.R

### Output

Summary of the progressive filtering applied independently to BrumiR-derived de novo miRNAs and miRDeep2 annotated miRNAs, including:

- differentially expressed miRNAs
- miRNAs with predicted seed matches
- target genes
- predicted miRNA–mRNA pairs
- coherent interactions
- validated interactions retained after miRanda or multiMiR

---

## Figure 5C – Validated coherent miRNA–mRNA interactions

### Scripts

- Figure5C_plot_validated_coherent_pairs_lollipop.R

### Output

Lollipop plot showing representative validated coherent miRNA–mRNA interactions supported by miRanda (de novo miRNAs) or multiMiR (annotated miRNAs), ranked according to miRNA log2 fold change.

---

## Figure 5D – Gene Ontology enrichment of coherent target genes

### Scripts

- Figure5D_prepare_source_specific_enrichment.R
- Figure5D_plot_source_specific_GO_enrichment.R

### Output

Gene Ontology (GO) Biological Process enrichment analysis performed separately for validated targets regulated by de novo and annotated miRNAs.

The same enrichment workflow also generates the KEGG and Reactome analyses presented in Supplementary Figure 4.

---

## Figure 5E – Integrated miRNA–mRNA regulatory network

The final regulatory network was assembled manually in Cytoscape using the node and edge tables generated by the nf-Sarcopipe pipeline.

Node layout, colors and graphical adjustments were performed manually for publication.

---

## Figure 5F – Validated interactions with sarcopenia-associated genes

### Scripts

- Figure5F_extract_sarcopenia_3UTRs_from_GTF.py
- Figure5F_seed_match_sarcopenia_targets.py
- Figure5F_validate_denovo_sarcopenia_targets_with_miranda.py
- Figure5F_validate_known_sarcopenia_targets_with_multimir.py
- Figure5F_prepare_validated_sarcopenia_network.py

### Supporting files

- Figure5F_sarcopenia_gene_set.tsv
- Figure5F_sarcopenia_gene_symbols.txt

### Output

- Seed-based prediction against a curated set of skeletal muscle genes associated with sarcopenia.
- Validation of predicted interactions using miRanda (de novo miRNAs) and multiMiR (annotated miRNAs).
- Node and edge tables used to construct the sarcopenia-focused regulatory network presented in Figure 5F.
- Input tables for the visualization shown in Supplementary Figure 4C.

---

## Notes

This directory contains the downstream scripts used for coherent miRNA–mRNA integration, functional enrichment, validation of predicted interactions, and generation of the manuscript figures.

The complete analytical workflow is implemented in the nf-Sarcopipe pipeline. This repository contains only the scripts and supporting files required to reproduce the manuscript figures.
