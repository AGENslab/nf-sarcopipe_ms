# Supplementary Figure 2 – Structural and sequence-based characterization of final de novo miRNA candidates identified by nf-Sarcopipe

This directory contains the scripts used to generate Supplementary Figure 2 and Supplementary Table 4 of the manuscript.

---

## Supplementary Figure S2A – Mature miRNA length distribution

### Script

- FigureS2A_sequence_length_distribution.R

### Output

- Comparison of mature miRNA length distributions between BrumiR-RF high-confidence de novo candidates and miRDeep2 annotated core miRNAs.

---

## Supplementary Figure S2B – Final de novo candidate summary

### Script

- FigureS2B_filter_top_BrumiR2Reference_candidates.sh

### Output

- Summary table describing the final structurally supported de novo miRNA candidates, including original BrumiR cluster, group of origin, cluster size, and candidate classification.

**Note**

The publication table was manually assembled from the BrumiR2Reference-supported candidate catalog generated by the pipeline.

## Supplementary Figure S2C – Secondary structure characterization

### Scripts

- FigureS2C_run_RNAfold_denovo.py
- FigureS2C_parse_RNAfold_denovo.py

### Output

- RNAfold secondary structure prediction for the final de novo miRNA precursors.
- Minimum free energy (MFE).
- Dot-bracket secondary structure annotation.

**Note**

Final precursor structure panels were rendered using VARNA and manually assembled for publication.

## Supplementary Figure S2D – 7-mer seed-space analysis

### Scripts

- FigureS2D_build_known_seed_dictionary.py
- FigureS2D_scan_candidate_7mer_space.py
- FigureS2D_candidate_seed_heatmap.R

### Output

- Reference dictionary of known human canonical miRNA seeds.
- Exhaustive scan of every possible 7-mer across each mature de novo miRNA.
- Classification of canonical and non-canonical seed matches.
- Heatmap summarizing seed-space similarity across the final de novo candidates.

# Supplementary Table 4 – Sequence features of the final de novo miRNA candidates

### Script

- supp_table4.py

### Output

Table summarizing the final high-confidence de novo miRNA candidates, including:

- provisional miRNA identifier
- original BrumiR cluster
- mature sequence length
- mature sequence
- canonical seed (positions 2–8)
- differential expression (log2FC and adjusted p-value)
- regulation direction
- canonical seed match against miRBase
- matched miRNA family
- total number of possible 7-mers
- number of matching known 7-mers
- matching 7-mer sequences
- miRNA families identified across all matching 7-mer positions

## Workflow summary

Supplementary Figure 2 documents the prioritization of the final de novo miRNA candidates through complementary structural and sequence-based analyses.

The workflow consists of:

1. Comparison of mature miRNA length distributions.
2. Structural prioritization using BrumiR2Reference.
3. RNA secondary structure prediction and precursor visualization.
4. Comprehensive 7-mer seed-space analysis against known human miRNA seeds.
5. Compilation of the final sequence and seed annotation catalog (Supplementary Table 4).

All computational analyses were generated automatically by the provided scripts. Publication-quality figure layouts and summary tables were manually assembled from the corresponding outputs.
