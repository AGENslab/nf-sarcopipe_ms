# Figure 3 – Prioritization and structural characterization of de novo miRNA candidates identified by nf-Sarcopipe

This directory contains the scripts and supporting files used to generate the analyses presented in Figure 3 of the manuscript.

---

## Figure 3A – miRNA discovery workflow

This panel is a schematic representation of the miRNA discovery workflow implemented in nf-Sarcopipe.

The diagram was prepared manually and summarizes the following analysis steps.

### miRDeep2

- Detection of known miRNAs.
- Seed extraction (positions 2–8).
- Generation of unique seed sequences.

### BrumiR-RF

- De novo miRNA candidate detection.
- Core candidate selection.
- Structural validation using BrumiR2Reference.
- Seed extraction (positions 2–8).
- Selection of final de novo miRNA candidates.

## Figure 3E – Final BrumiR de novo miRNA candidates

This panel was assembled manually from the final prioritized BrumiR-RF candidate table generated after structural validation.

### Script

- Figure3E_extract_final_BrumiR_passfilter_candidates.py

### Output

- Figure3E_final_BrumiR_passfilter_candidates.tsv

The output table contains the final de novo candidates retained for downstream analyses, including genomic coordinates, mature sequence, precursor sequence, structural metrics, differential expression statistics, and regulation status.

---

## Notes

The scripts in this directory reproduce the analyses presented in Figure 3 using the outputs generated by the nf-Sarcopipe workflow.

Figure 3A, Figure 3D, and Figure 3E were assembled manually from the corresponding summary tables produced by these scripts. Structural validation using BrumiR2Reference and exact sequence comparison against MirGeneDB are performed within the nf-Sarcopipe workflow; only the downstream summarization and visualization steps are included in this repository.
