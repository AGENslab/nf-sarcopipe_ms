# Figure 3 – Prioritization and functional characterization of de novo miRNA candidates identified by nf-Sarcopipe.

This directory contains the scripts and supporting files used to generate the analyses presented in Figure 3 of the manuscript.

---

## Figure 3A – miRNA discovery workflow

This panel is a schematic representation of the miRNA discovery workflow implemented in nf-Sarcopipe.

The diagram was prepared manually and summarizes the following analysis steps:

### miRDeep2

- Detection of known miRNAs.
- Seed extraction (positions 2–8).
- Generation of unique seed sequences.

### BrumiR

- De novo miRNA candidate detection.
- Core candidate selection.
- Structural validation using BrumiR2Reference.
- Seed-based target prediction.
- Selection of final de novo candidates.

---

## Figure 3B – Structural validation using BrumiR2Reference

### Scripts

- Figure3B_analysis_BrumiR2Reference.py
- Figure3B_plot_BrumiR2Reference.R

### Input

- BrumiR2Reference output generated by the nf-Sarcopipe pipeline.

### Output

- Summary of supported and unsupported BrumiR candidates.
- Figure showing supported candidates in the Active, Shared and Sedentary groups.

## Figure 3D – Final differentially expressed miRNA candidates

This panel was assembled manually from the final differential expression results.

### Supporting files

- Figure3D_BrumiR_active.txt
- Figure3D_BrumiR_sedentary.txt
- Figure3D_miRDeep2_active.txt

---

## Figure 3E – Final BrumiR de novo candidates

This panel was assembled manually from the final BrumiR candidate table after structural validation.

### Supporting files

- Figure3E_BrumiR_final_candidates.tsv
- Figure3E_BrumiR_final_seeds.tsv

The candidate table contains the mature sequence, seed sequence, log2 fold change, adjusted p-value and final candidate name for each selected BrumiR miRNA.

Secondary structure validation was performed by BrumiR2Reference during the main nf-Sarcopipe workflow.

## Notes

This repository contains the scripts and supporting files used to reproduce the manuscript figures.

The complete BrumiR2Reference execution and other intermediate files are part of the main nf-Sarcopipe pipeline and are therefore not duplicated in this repository.
