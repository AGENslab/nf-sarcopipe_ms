# Figure 2 – Overview and statistical characterization of circulating miRNA expression profiles analyzed with nf-Sarcopipe.

This directory contains the scripts and supporting files used to generate the analyses presented in Figure 2 of the manuscript.

---

## Figure 2A – Public sRNA-seq dataset

This panel summarizes the public small RNA sequencing dataset analyzed in this study.

The diagram was prepared manually and illustrates:

- Active group (synchronized swimmers).
- Sedentary group (healthy young women).
- Plasma samples used for small RNA sequencing.
- Analysis performed using the nf-Sarcopipe workflow.
- Combined reference-guided and de novo miRNA discovery strategies.

## Notes

The scripts in this directory reproduce the statistical analyses and figures included in Figure 2.

The workflow starts from the processed count matrices generated by the nf-Sarcopipe pipeline and performs differential expression analysis, visualization and exploratory analyses.
