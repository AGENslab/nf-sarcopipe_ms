# Figure 2 – Overview and statistical characterization of circulating miRNA expression profiles analyzed with nf-Sarcopipe

This directory contains the scripts and supporting files used to generate the analyses presented in Figure 2 of the manuscript.

---

## Figure 2A – Public sRNA-seq dataset

This panel summarizes the public small RNA sequencing dataset analyzed in this study.

The diagram was prepared manually and illustrates:

- Active group (synchronized swimmers).
- Sedentary group (healthy young women).
- Plasma samples used for small RNA sequencing.
- Analysis performed using the nf-Sarcopipe workflow.
- Combined reference-guided and de novo miRNA discovery strategies.

---

## Figure 2B – Core miRNA sets

This panel was assembled manually from summary tables generated by the nf-Sarcopipe pipeline.

It shows Venn diagrams summarizing the core miRNA sets identified for each method and condition.

For BrumiR-RF, candidate miRNAs clustered at 95% sequence identity were filtered using a presence threshold of 0.8.

For miRDeep2, known miRNAs (miRBase-annotated) were filtered using a presence threshold of 0.8, whereas novel predictions were filtered using a threshold of 0.3.

Presence thresholds were selected to ensure sufficient representation of detectable miRNA features across samples while maintaining consistency between methods. Accordingly, only BrumiR-RF candidates passing the 0.8 threshold were retained for downstream analyses. miRDeep2 novel predictions were not considered in downstream analyses.

### Scripts

- Figure2B_prepare_venn_counts.py
- figure_2B_venn_core_2set.py

### Output

The scripts generate the summary tables used to manually assemble the Venn diagrams.

## Notes

The scripts in this directory reproduce the statistical analyses and visualizations included in Figure 2.

The workflow starts from the processed miRNA count matrices generated by the nf-Sarcopipe pipeline and performs differential expression analysis, exploratory analyses, and figure generation. Figure 2B is an exception, as the Venn diagrams were assembled manually using the summary tables produced by the accompanying Python scripts.
