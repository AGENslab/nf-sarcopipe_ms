# nf-Sarcopipe Manuscript Scripts

This repository contains the scripts used to generate the figures and supplementary material presented in the **nf-Sarcopipe** manuscript.

The scripts are organized according to the corresponding figures and supplementary items described in the manuscript.

---

## Repository structure

```
manuscript/
├── figure2/
├── figure3/
├── figure4/
├── figure5/
├── supplementary1/
├── supplementary2/
├── supplementary3/
├── supplementary4/
└── supp_table1/
```

Each directory contains:

- Scripts used to generate the corresponding figure or supplementary material.
- A README describing the analysis workflow, required inputs, and generated outputs.

## Reproducibility

The scripts in this repository were used to generate the analyses and visualizations presented in the manuscript from the processed outputs of the nf-Sarcopipe pipeline.
