# nf-Sarcopipe Manuscript Scripts

This repository contains the scripts used to generate the figures and supplementary material presented in the nf-Sarcopipe manuscript.

## Repository structure

```
manuscript/
├── figure2/
├── figure3/
├── figure4/
├── figure5/
├── supplementary1/
├── supplementary2/
├── supplementary3/
└── supplementary4/
└── supp_table1/
```

Each directory contains:

- Scripts used to generate the corresponding figure.
- A README describing the analysis workflow and expected outputs.
